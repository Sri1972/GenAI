# FairSplit — Group Expense Splitter

A mobile-first web app for splitting bills among friends after group dinners, trips, or shared housing expenses. Users photograph a receipt, the app extracts line items via OCR, and people claim which items they ordered. It calculates who owes whom (minimizing the number of transactions), handles tax/tip proportionally, and sends payment reminders via text. Supports recurring splits for roommates (rent, utilities). Built with React Native Web, Node.js backend, and PostgreSQL.
