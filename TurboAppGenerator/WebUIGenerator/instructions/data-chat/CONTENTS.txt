DATA CHAT DOMAIN — AI Excel Chat
==================================

App Name: ai-excel-chat
Theme: Data analysis tool — clean, minimal, focused
Accent: #4F46E5 (indigo-600)
Style: Light mode, split-pane layout (upload left, chat right)

PAGES:
  1. Chat Interface — Upload Excel + AI chat about the data
     - File upload with drag-and-drop
     - Auto-parse worksheets and detect column types
     - Natural language questions → chart/table responses
     - AI generates inline visualizations from user queries

CHART TYPES EXERCISED (dynamically generated by AI from uploaded data):
  - Line chart (trend detection)
  - Bar chart (category comparison)
  - Pie/donut chart (proportion breakdown)
  - Scatter plot (correlation analysis)
  - Histogram (distribution analysis)
  - Area chart (cumulative trends)

DATA TABLES:
  - No fixed tables — user uploads any .xlsx/.xls file
  - Parsing happens SERVER-SIDE via the data-chat skill's api_server.py
    (no xlsx library on the frontend — the client stays lean, per ai-excel-chat.md)
