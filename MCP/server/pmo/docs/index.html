PMO MCP Server

A robust, modular, and metadata-driven Model Context Protocol server for intelligent Project & Resource Management

🌟 Overview

The PMO MCP Server is a comprehensive solution for managing projects, resources, and allocations through an intelligent, LLM-powered interface. Built on the Model Context Protocol (MCP), it provides seamless integration with Claude Desktop, GPT, Gemini, and other AI assistants.

🧩
Modular Architecture
Clean separation of concerns with dedicated modules for config, tools, utils, and core functionality
⚙️
Configuration Management
External YAML configuration with environment variable support for flexible deployment
📋
Metadata-Driven
Rich metadata system providing business context, validation rules, and field descriptions
🔄
Robust API Client
Built-in retry logic, timeout handling, and connection management for reliable operations
✅
Comprehensive Validation
Input validation for all fields with detailed, helpful error messages
📝
Externalized Prompts
All prompts in separate YAML files for easy customization without code changes
✨ What's New in v2.0: Complete refactoring with modular design, enhanced error handling, custom exception classes, structured logging, and metadata caching for improved performance.

🔄 Data Flow

  1. Client Request: LLM client sends tool invocation via MCP
  2. Validation: Server validates input parameters using validators
  3. API Call: API client makes HTTP request with retry logic
  4. Metadata Enrichment: Response enriched with business context
  5. Response: Formatted response sent back to LLM client

🚀 Quick Start

Installation

Prerequisites: Python 3.11+, PMO API running on http://localhost:5000

1. Install Dependencies

pip install -r requirements.txt # Or with uv uv pip install -r requirements.txt

2. Configure Environment

# Copy example environment file cp config/.env.example config/.env # Edit .env with your settings # PMO_API_BASE_URL=http://localhost:5000 # PMO_LOG_LEVEL=INFO

3. Start the Server

python server.py

Claude Desktop Integration

Add to your Claude Desktop configuration (claude_desktop_config.json):

{ "mcpServers": { "pmo": { "command": "python", "args": ["D:\\GenAI\\MCP\\server\\pmo\\server.py"], "env": { "PMO_API_BASE_URL": "http://localhost:5000" } } } }
✅ That's it! The server is now ready to use with your LLM client. Try asking: "Show me all active projects" or "What is the capacity allocation for resource ID 5?"

⚙️ Configuration

Environment Variables

Variable Description Default
PMO_API_BASE_URL PMO API backend URL http://localhost:5000
PMO_API_TIMEOUT API request timeout (seconds) 30
PMO_LOG_LEVEL Logging level INFO
PMO_SERVER_DEBUG Enable debug mode false

YAML Configuration

Advanced settings can be configured in config/config.yaml:

api: base_url: "http://localhost:5000" timeout: 30 retry_attempts: 3 retry_delay: 1 server: name: "PMO" version: "2.0.0" debug: false log_level: "INFO" validation: strict_mode: true allowed_intervals: - "Weekly" - "Monthly" - "Quarterly" metadata: cache_enabled: true reload_on_change: true

Customizing Prompts

Edit config/prompts.yaml to customize LLM prompts:

prompts: tool_selection_guide: title: "Tool Selection Guide" content: | Guide for selecting the correct MCP tool... project_overview: title: "Project Overview Analysis" content: | Generate a comprehensive project overview...

🛠️ Troubleshooting

Common Issues

❌ "Failed to connect to PMO API"
  • Check if PMO API is running: curl http://localhost:5000/health
  • Verify PMO_API_BASE_URL is correct
  • Check firewall settings
❌ "Metadata file not found"
  • Ensure metadata files exist in metadata/ directory
  • Check file permissions
  • Verify file names match expected patterns
❌ "Invalid date format"
  • Dates must be in YYYY-MM-DD format
  • Example: "2024-01-15"
  • Use ISO 8601 standard

Debug Mode

Enable detailed logging for troubleshooting:

# Set in .env PMO_SERVER_DEBUG=true PMO_LOG_LEVEL=DEBUG
💡 Pro Tip: Check the logs in your terminal when running the server. All API calls, validation errors, and metadata operations are logged for debugging.
