🌟 System Overview

What is the PMO MCP Server?

The PMO MCP Server is a Model Context Protocol server that exposes intelligent Project & Resource Management tools to LLM clients like Claude Desktop. It provides a comprehensive suite of tools for managing projects, resources, allocations, and organizational structures with metadata-driven intelligence.

🚀 Key Innovation: Metadata-driven architecture that enriches every tool response with business context, field validation, and intelligent insights!

📁 Metadata System

Why Metadata Drives Intelligence

The PMO MCP Server's metadata system is what makes it truly intelligent. Every tool response is enriched with business context, field descriptions, validation rules, and relationship information derived from comprehensive JSON metadata files.

🧠 Intelligent Features: Field validation, business meaning context, constraint checking, enum value suggestions, and relationship mapping - all driven by metadata!

🛠️ Troubleshooting

Common Issues & Solutions

1. "MCP server connection failed"

Solutions:
  • Verify Python path in Claude Desktop config
  • Check that pmo_comprehensive.py exists and is executable
  • Ensure all dependencies are installed: pip install -r requirements.txt
  • Restart Claude Desktop after configuration changes

2. "API request failed: 500/502 errors"

Solutions:
  • Ensure PMO API backend is running on localhost:5000
  • Check API health: curl http://localhost:5000/projects
  • Verify database connectivity and schema
  • Check API logs for detailed error information

3. "Pydantic validation error" for tools

Solutions:
  • API response shape changed - tools normalize responses automatically
  • Check if API returns list vs dict format (tools handle both)
  • Verify metadata constraints match actual data formats
  • Update metadata files if business rules changed

Debug Mode

Enable detailed logging for troubleshooting:

# The MCP server includes detailed API call logging # Look for these in Claude Desktop console: # "API Call: GET http://localhost:5000/projects" # "Params: {param_dict}" # "API Response type: {type}"

System Requirements

  • Python: 3.8 or higher
  • Dependencies: FastMCP, requests, typing extensions
  • Backend API: PMO REST API running on localhost:5000
  • Metadata: JSON metadata files in server/pmo/metadata/
  • Claude Desktop: Latest version with MCP support
💡 Pro Tips:
  • Start with simple queries like "Show all projects" to verify connectivity
  • Use metadata tools to explore available fields and endpoints
  • Check that your PMO API backend returns expected data formats
  • Metadata files provide rich context - keep them updated with business changes
  • The server handles both list and dict API responses automatically
