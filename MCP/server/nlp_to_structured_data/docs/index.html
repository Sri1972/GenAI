🛠️ Troubleshooting

🔍 Metadata Issues

Issue: "No metadata found during auto-discovery"
Solution: Check metadata file structure:
  • Same directory: data.csv + data.metadata.json
  • Metadata folder: data/csv/data.csv + metadata/csv/data.metadata.json
Issue: "0 columns with metadata" despite loading metadata file
Solution: Check metadata structure - columns should be in:
  • data_dictionary.columns (CSV format)
  • columns (direct format)
  • schema.columns (schema format)

🧠 Intelligence Issues

Issue: Queries not finding correct columns
Solution: Ensure metadata includes business_meaning for columns: 
"TotalAmount": {
  "business_meaning": "Total transaction value for financial reporting"
}

⚙️ System Issues

Issue: Server initialization failures
Solution:
  • Check Python path configuration
  • Verify MCP dependencies: pip install mcp
  • Ensure all infrastructure files are present
  • Restart Claude Desktop after configuration changes
