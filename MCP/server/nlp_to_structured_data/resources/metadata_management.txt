Metadata Management System

METADATA STRUCTURE:
The system supports comprehensive metadata files that enhance data analysis with business context.

SUPPORTED FORMATS:
- JSON: .metadata.json, _metadata.json
- YAML: .metadata.yaml, _metadata.yaml

AUTO-DISCOVERY PATTERNS:
For file "sales_data.csv", the system automatically looks for:
1. sales_data.metadata.json
2. sales_data.metadata.yaml  
3. sales_data_metadata.json
4. sales_data_metadata.yaml
5. metadata/sales_data.json
6. metadata/sales_data.yaml

METADATA SCHEMA:
{
  "metadata_version": "1.0",
  "description": "Business description of the dataset",
  "created_date": "ISO date string",
  "columns": {
    "column_name": {
      "data_type": "string|number|date|boolean",
      "business_meaning": "Human-readable description",
      "format": "Expected format or pattern",
      "constraints": {
        "required": true|false,
        "min_value": number,
        "max_value": number,
        "allowed_values": ["list", "of", "values"]
      },
      "examples": ["sample", "values"]
    }
  },
  "business_rules": {
    "validation_rules": ["Rule descriptions"],
    "calculations": {"formula_name": "business logic"},
    "relationships": ["Cross-column dependencies"]
  },
  "data_lineage": {
    "source_systems": ["System names"],
    "transformations": ["Applied transformations"],
    "update_frequency": "daily|weekly|monthly"
  }
}
