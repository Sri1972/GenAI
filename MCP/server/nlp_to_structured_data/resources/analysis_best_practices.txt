Data Analysis Best Practices

QUERY OPTIMIZATION:
1. Start with data exploration: "Describe the dataset"
2. Understand column meanings before filtering
3. Use metadata when available for business context
4. Check data quality before analysis

EFFECTIVE QUERY PATTERNS:
- Be specific: "Show top 5 customers by revenue" vs "Show top customers"
- Include context: "Compare Q1 vs Q2 sales performance"
- Ask for insights: "What patterns do you see in customer behavior?"
- Request formatting: "Show results as a table with percentages"

ANALYSIS WORKFLOW:
1. Load data with metadata if available
2. Explore data structure and quality
3. Apply filters or aggregations as needed
4. Generate insights and recommendations
5. Validate results against business rules

COMMON OPERATIONS:
- Filtering: "Show records where revenue > 10000"
- Aggregation: "Calculate total sales by region"
- Grouping: "Break down performance by product category"
- Sorting: "Rank customers by purchase frequency"
- Analysis: "Identify trends in the time series data"

DATA QUALITY CHECKS:
- Missing values: "What percentage of data is missing?"
- Duplicates: "Are there duplicate entries?"
- Outliers: "Identify unusual values in revenue column"
- Consistency: "Check for data format inconsistencies"

PERFORMANCE TIPS:
- Large datasets: Use sampling for initial exploration
- Complex queries: Break into smaller steps
- Memory usage: Monitor for large datasets
- Response time: Use caching when appropriate

BUSINESS CONTEXT:
- Always consider business meaning of columns
- Apply domain knowledge to interpret results
- Validate findings against known business rules
- Provide actionable recommendations
