Overview

The D3 Chart MCP Server is a Model Context Protocol server that provides interactive D3.js and Chart.js visualization capabilities. It wraps the existing d3_chart_api_server.py backend and exposes 9 chart generation tools through a proper MCP interface.

✨ Key Features

  • 9 Chart Types: Line, Bar, Grouped Bar, Pie/Donut, Scatter, Bubble, Heatmap
  • Multiple Data Formats: Chart.js, PMO allocation, simple arrays, object arrays
  • Auto-Detection: Intelligent chart type selection based on data structure
  • Interactive: Hover tooltips, legends, responsive sizing
  • Dual Rendering: Chart.js for most charts, D3.js for pie/donut specializations
  • Standalone Output: Self-contained HTML files with embedded data
📍 Location: D:\GenAI\MCP\server\charts\mcp-d3-stdio-custom\
🎯 Main Server: d3_chart_mcp.py
🔧 Backend API: d3_chart_api_server.py
🎨 Renderer: chart_renderer.py

Why This Server?

The D3 Chart MCP Server solves the challenge of generating professional, interactive visualizations from structured data within the MCP ecosystem. It provides:

  • Consistent chart rendering across PMO, analytics, and data exploration workflows
  • Automatic data format detection and normalization
  • Beautiful, publication-ready charts with minimal configuration
  • Integration with the PMO MCP Client for seamless data-to-visualization pipelines

Architecture

The server uses a three-layer architecture to separate concerns:

🔷 Layer 1: MCP Interface d3_chart_mcp.py

FastMCP-based server exposing 9 chart generation tools and 2 documentation resources. Handles MCP protocol communication and tool registration.

↓

🔷 Layer 2: API Backend d3_chart_api_server.py

STDIO JSON-RPC server that processes chart requests. Spawned as subprocess, receives JSON payloads, returns chart status and file paths.

↓

🔷 Layer 3: Renderer chart_renderer.py

Core rendering engine with intelligent data normalization. Detects data patterns, selects appropriate chart types, generates HTML with embedded JavaScript.

Communication Flow

1
MCP Client Request
PMO Client calls create_line_chart() tool via MCP protocol
2
MCP Server (FastMCP)
d3_chart_mcp.py receives tool call and invokes call_d3_api()
3
Subprocess Spawn
Launches d3_chart_api_server.py as STDIO subprocess with JSON payload
4
API Processing
API server parses request and delegates to chart_renderer.py
5
Data Normalization
Renderer analyzes data structure, detects patterns, selects chart type
6
HTML Generation
Generates standalone HTML with embedded JSON and Chart.js/D3.js code
7
File Output
Writes to html-charts/chart_TIMESTAMP.html
8
Response Path
Returns success status and file path up through API → MCP Server → Client
💡 Design Pattern: The wrapper pattern allows the existing STDIO API server to remain unchanged while providing a true MCP interface for broader compatibility.

Chart Tools

The server provides 9 chart generation tools, each accepting flexible data formats.

create_line_chart TOOL

Create interactive D3.js line chart with smooth curves and hover interactions.

title string optional
Chart title (default: "Line Chart")
data Dict | List optional
Chart data in Chart.js format or raw data
labels List[str] optional
X-axis labels (if data not in Chart.js format)
datasets List[Dict] optional
Data series (if data not in Chart.js format)

Returns: Path to generated HTML file

create_bar_chart TOOL

Create vertical bar chart with single or multiple series.

stacked bool optional
Create stacked bar chart (default: false)

Other parameters same as create_line_chart

create_grouped_bar_chart TOOL

Create side-by-side grouped bars with legend and tooltips. Enhanced for PMO project allocation.

Parameters same as create_line_chart

create_pie_chart TOOL

Create pie or donut chart with segment colors and value labels.

donut bool optional
Create donut chart with inner radius (default: false)
values List[float] optional
Values for each category

create_scatter_plot TOOL

Create scatter plot for correlation analysis.

points List[Dict] optional
Points with x, y, r (radius), color, label properties

create_bubble_chart TOOL

Create bubble chart with three-dimensional data (x, y, radius).

datasets List[Dict] optional
Datasets containing bubble data points [{x, y, r}]

create_heatmap TOOL

Create 2D intensity grid with color mapping.

x_labels List[str] optional
X-axis category labels
y_labels List[str] optional
Y-axis category labels
values List[List[float]] optional
2D matrix where values[y][x] is intensity

render_chart_from_dataset TOOL

Universal renderer with intelligent chart type routing.

chart_type string optional
Hint: line, bar, pie, grouped_bar, scatter, etc. (default: "line")

Auto-detects optimal chart type if not specified.

Chart Renderer

The chart_renderer.py module contains the core rendering logic with intelligent data normalization.

Key Function: render_chart_html_from_dataset()

def render_chart_html_from_dataset(
    data_obj, 
    title_text: str = "Chart", 
    chart_type: str | None = None
) -> str

Data Normalization Pipeline

  1. Input Detection: Identifies data structure (dict with 'result', list of records, Chart.js format)
  2. Field Analysis: Detects label fields (month, date, time), name fields (project_name), numeric fields
  3. Chart Type Selection: Applies heuristics based on data shape and field names
  4. Format Conversion: Transforms to Chart.js labels/datasets structure
  5. Template Selection: Chooses Chart.js or D3.js template based on chart type
  6. HTML Generation: Embeds data as JSON in script tag, initializes visualization

Auto-Detection Heuristics

PatternDetected TypeLogic
Single numeric field + categorical labelsPie ChartNatural part-to-whole representation
Project name + planned/actual fieldsGrouped BarBudget vs actual comparison
Time-like labels + multiple numericsLine ChartTime series trends
X/Y/R coordinate pointsScatter/BubbleCorrelation or 3D data

Template Engines

Chart.js Template (Default)

Used for: Line, Bar, Grouped Bar, Scatter, Bubble, Heatmap

  • UMD bundle from CDN
  • Responsive canvas rendering
  • Custom legend with totals
  • Data embedded in <script id="chart-data">

D3.js Template (Pie/Donut)

Used for: Pie and Donut charts

  • D3.js v7 from CDN
  • SVG-based rendering
  • Custom tooltips and animations
  • Arc generators with configurable inner radius
⚠️ Important: The renderer automatically strips cumulative/running total fields to avoid double-counting in stacked visualizations.

Data Formats

1. Chart.js Format (Recommended)

{
  "labels": ["Q1", "Q2", "Q3", "Q4"],
  "datasets": [{
    "label": "Revenue",
    "data": [120000, 150000, 180000, 200000],
    "backgroundColor": "#1f77b4"
  }]
}

2. PMO Project Allocation

[{
  "month": "2025-01",
  "resource_id": 1,
  "project_allocation_details": [
    {"project_name": "Alpha", "planned_percentage": 60},
    {"project_name": "Beta", "planned_percentage": 40}
  ]
}]

3. Scatter Plot Format

{
  "points": [
    {"x": 10, "y": 20, "r": 5, "label": "Point A"},
    {"x": 15, "y": 25, "r": 8, "label": "Point B"}
  ]
}

4. Heatmap Format

{
  "xLabels": ["Mon", "Tue", "Wed"],
  "yLabels": ["Week 1", "Week 2"],
  "values": [[10, 15, 12], [8, 12, 16]]
}

5. Simple Arrays

[100, 150, 200, 175, 225]

Auto-converted to Chart.js format with numeric labels.

6. Object Arrays

[
  {"month": "Jan", "sales": 100, "expenses": 80},
  {"month": "Feb", "sales": 150, "expenses": 95}
]

Renderer extracts label field and numeric fields automatically.

Examples

Example 1: Simple Line Chart

# Via MCP tool call
create_line_chart(
    title="Monthly Sales",
    labels=["Jan", "Feb", "Mar"],
    datasets=[{
        "label": "Sales",
        "data": [100, 150, 200]
    }]
)

Example 2: Grouped Bar (PMO Projects)

create_grouped_bar_chart(
    title="Project Hours - January 2025",
    data={
        "labels": ["Project Alpha", "Project Beta"],
        "datasets": [
            {"label": "Planned", "data": [120, 80]},
            {"label": "Actual", "data": [110, 95]}
        ]
    }
)

Example 3: Pie Chart from Simple Data

create_pie_chart(
    title="Market Share",
    labels=["Product A", "Product B", "Product C"],
    values=[45, 30, 25]
)

Example 4: Auto-Detection

# Renderer auto-detects pie chart
data = [
    {"category": "Engineering", "headcount": 50},
    {"category": "Sales", "headcount": 30},
    {"category": "Marketing", "headcount": 20}
]

render_chart_from_dataset(
    title="Department Headcount",
    data=data
    # chart_type automatically detected as 'pie'
)

Example 5: Scatter Plot

create_scatter_plot(
    title="Task Complexity vs Duration",
    points=[
        {"x": 5, "y": 120, "label": "Task A"},
        {"x": 8, "y": 200, "label": "Task B"},
        {"x": 3, "y": 80, "label": "Task C"}
    ]
)
