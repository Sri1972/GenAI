# Chart Library Scripts

This directory contains local copies of JavaScript charting libraries with automatic CDN fallback.

## Directory Structure

```
scripts/
├── d3_js/
│   └── d3.v7.min.js         (273 KB) - D3.js v7 visualization library
├── chart_js/
│   ├── chart.umd.min.js     (200 KB) - Chart.js v4.4.0 charting library
│   └── chartjs-plugin-datalabels.min.js (13 KB) - DataLabels plugin
└── html2canvas/
    └── html2canvas.min.js   (194 KB) - html2canvas v1.4.1 for clipboard export
```

## Total Size: ~680 KB

## Features

### 1. Local-First with CDN Fallback
Charts generated by the MCP server automatically use these local files with fallback to CDN:

1. **Local First**: Tries to load from `scripts/` directory
2. **Automatic Fallback**: If local file missing, loads from CDN
3. **Zero Configuration**: Transparent to users

### 2. Automatic PNG Generation ⭐ NEW
When a chart is created, a PNG screenshot is automatically generated alongside the HTML file:
- **Auto-generated**: PNG created automatically (no manual action needed)
- **Same filename**: `chart_name.html` → `chart_name.png`
- **High resolution**: 1400x900px with 2x scale for crisp quality
- **PowerPoint ready**: Perfect for presentations, documents, emails

### 3. Copy to Clipboard Button ⭐ NEW
Every chart includes a "📋 Copy Chart" button in the top-right corner:
- **One-click copy**: Click button to copy chart as image to clipboard
- **Direct paste**: Paste into PowerPoint, Word, Slack, Teams, etc.
- **No tools needed**: Works directly in the browser
- **High quality**: Exports at 2x resolution for clarity

## Configuration

Library paths are configured in constants at the top of each file:

### D3.js Configuration (`d3_chart_api_server.py`)
```python
D3_LOCAL_PATH = '../scripts/d3_js/d3.v7.min.js'
D3_CDN_URL = 'https://d3js.org/d3.v7.min.js'
D3_SCRIPT_TAG = f"<script src='{D3_LOCAL_PATH}' onerror=\"this.onerror=null; this.src='{D3_CDN_URL}';\"></script>"
```

### Chart.js Configuration (`chart_renderer.py`)
```python
CHARTJS_LOCAL_PATH = '../scripts/chart_js/chart.umd.min.js'
CHARTJS_CDN_URL = 'https://cdn.jsdelivr.net/npm/chart.js@4.4.0/dist/chart.umd.min.js'
CHARTJS_DATALABELS_LOCAL_PATH = '../scripts/chart_js/chartjs-plugin-datalabels.min.js'
CHARTJS_DATALABELS_CDN_URL = 'https://cdn.jsdelivr.net/npm/chartjs-plugin-datalabels@2.2.0/dist/chartjs-plugin-datalabels.min.js'
```

### html2canvas Configuration (`d3_chart_api_server.py` and `chart_renderer.py`)
```python
HTML2CANVAS_LOCAL_PATH = '../scripts/html2canvas/html2canvas.min.js'
HTML2CANVAS_CDN_URL = 'https://cdn.jsdelivr.net/npm/html2canvas@1.4.1/dist/html2canvas.min.js'
```

## PowerPoint Workflow

### Option 1: Use Auto-Generated PNG (Recommended)
1. Generate chart using MCP client
2. Navigate to `html-charts/` folder
3. Find the `.png` file (same name as HTML)
4. Insert into PowerPoint via Insert → Pictures

### Option 2: Copy to Clipboard Button (Fastest)
1. Open chart HTML file in browser
2. Click "📋 Copy Chart" button in top-right corner
3. Switch to PowerPoint
4. Press Ctrl+V to paste
5. Done! ✓

### Option 3: Manual Screenshot
1. Open chart HTML file in browser
2. Use Windows Snipping Tool or browser screenshot
3. Save and insert into PowerPoint

## Updating Libraries

To update to newer versions:

1. Download new library files
2. Replace files in appropriate directory
3. Update version numbers in constants (if URL changed)

### Update D3.js
```powershell
cd scripts/d3_js
Invoke-WebRequest -Uri "https://d3js.org/d3.v7.min.js" -OutFile "d3.v7.min.js"
```

### Update Chart.js
```powershell
cd scripts/chart_js
Invoke-WebRequest -Uri "https://cdn.jsdelivr.net/npm/chart.js@4.4.0/dist/chart.umd.min.js" -OutFile "chart.umd.min.js"
Invoke-WebRequest -Uri "https://cdn.jsdelivr.net/npm/chartjs-plugin-datalabels@2.2.0/dist/chartjs-plugin-datalabels.min.js" -OutFile "chartjs-plugin-datalabels.min.js"
```

### Update html2canvas
```powershell
cd scripts/html2canvas
Invoke-WebRequest -Uri "https://cdn.jsdelivr.net/npm/html2canvas@1.4.1/dist/html2canvas.min.js" -OutFile "html2canvas.min.js"
```

## Screenshot Utility

For manual PNG generation or batch processing:

```powershell
# Single file
python utils/screenshot.py path/to/chart.html

# Custom output path
python utils/screenshot.py path/to/chart.html output.png

# From Python code
from utils.screenshot import capture_html_as_png
png_path = capture_html_as_png('chart.html', width=1400, height=900)
```

## Disabling Auto-Screenshot

To disable automatic PNG generation (faster chart creation):

```python
# In your code
save_html(html_content, auto_screenshot=False)
```
