🏗️ System Architecture

The NLP Data Chat Client uses a revolutionary agent-free architecture for direct, high-performance data analysis.

Layered Architecture

🖥️ Layer 1: NLP Data Chat Client nlp_to_structured_data_chat_client.py

Command-line interface with fast/enhanced modes. Provides interactive sessions, single-message queries, and auto-metadata discovery for CSV, Excel, and JSON data sources.

↓

🔌 Layer 2: STDIO Protocol Model Context Protocol

Secure bidirectional communication channel using standard input/output streams. Enables seamless integration with Claude Desktop and MCP-compatible tools.

↓

⚙️ Layer 3: Structured Data MCP Server structured_data_analysis_mcp_server.py

FastMCP-based server with direct service integration. Exposes tools for data loading, querying, and analysis without agent middleware overhead.

↓

🔧 Layer 4: Data Services CSV, Excel, JSON

Format-specific processing engines with Pandas integration. Direct service calls provide enhanced JSON flattening, intelligent statistics, and ASCII-only output.

↓

🧠 Layer 5: Claude AI + Data Sources LLM Service & Files

Claude Bedrock integration with timeout controls for natural language processing. Accesses files and metadata for context-aware, intelligent analysis and insights.

Request Processing Flow

1
User Query
User enters natural language query via CLI: --message "Show top customers" or interactive mode
2
Client Processing
Client validates data is loaded, determines mode (fast/enhanced), formats MCP request with metadata context
3
STDIO Transport
MCP request sent via STDIO protocol to server process, ensuring secure isolated communication
4
Server Tool Routing
Server identifies appropriate tool (query_data), extracts parameters, routes to service layer
5
Service Execution
CSV/Excel/JSON service processes data using Pandas, applies filters, generates statistics and preview
6
LLM Enhancement
If enhanced mode: Claude AI formats results with business insights, natural language explanations, and recommendations
7
Response Delivery
Formatted response returned via STDIO, client displays results with proper formatting and context
✨ Key Innovation: No agent layer! Direct service integration eliminates middleware overhead, providing 3x faster performance (0.2s fast mode) and simplified debugging.
💡 Performance Modes: Fast mode (server-only, 0.2s) for quick exploration. Enhanced mode (with Claude AI, 3-15s) for deep business insights and recommendations.

🔌 Model Context Protocol (MCP) System

What is MCP?

Model Context Protocol is a standardized way for AI models to interact with external tools and data sources. Our system implements MCP to enable seamless integration with Claude Desktop and other AI platforms.

MCP Tools Available

Tool Name Purpose Parameters
load_data Load data from file with metadata file_path, file_type, metadata_path (optional)
load_sample_data Load built-in sample datasets data_type (sales, hr, inventory)
query_data Natural language data querying query

Claude Desktop Integration

To use this system with Claude Desktop:

{ "mcpServers": { "nlp-structured-data": { "command": "python", "args": [ "D:/GenAI/MCP/nlp_to_structured_data/structured_data_analysis_mcp_server.py" ] } } }

📋 Metadata System

Why Metadata Matters

Metadata provides crucial business context that transforms raw data into meaningful insights. It includes column descriptions, business rules, data types, and relationships.

Metadata Structure

{ "dataset_info": { "name": "Sales Performance Data", "description": "Monthly sales data for analysis", "source": "CRM System", "last_updated": "2025-10-25" }, "columns": { "company": { "description": "Customer company name", "data_type": "string", "business_meaning": "Primary customer identifier", "category": "identifier" }, "revenue": { "description": "Total sales revenue", "data_type": "float", "unit": "USD", "business_meaning": "Gross revenue in US dollars", "validation_rules": { "min_value": 0, "max_value": 10000000 } } }, "business_rules": { "data_validation": { "revenue_check": "Revenue should be positive" }, "business_logic": { "profit_calculation": "Profit = Revenue - Costs" } } }

Auto-Discovery Features

  • File Pattern Matching: Automatically finds .metadata.json files
  • Format Support: JSON and YAML metadata formats
  • Template Generation: Creates metadata templates from data structure
  • Caching: Efficient metadata caching for performance
# Auto-discovery patterns: # data.csv → looks for data.metadata.json # data.csv → looks for data_metadata.json # data.csv → looks for metadata.json in same directory

🛠️ Troubleshooting

Common Issues

1. "Failed to initialize Claude Bedrock"

Solution:
  • Check your .env file has correct AWS credentials
  • Verify AWS Bedrock access permissions
  • Ensure AWS region is correctly configured

2. "MCP server not responding"

Solution:
  • Check Python path in Claude Desktop config
  • Verify all dependencies are installed
  • Restart Claude Desktop application

3. "Unsupported file type"

Solution:
  • Verify file extension matches --type parameter
  • Check if file format is supported (csv, excel, json)
  • Ensure file is not corrupted

Debug Mode

For detailed troubleshooting information:

# Run with verbose logging export DEBUG=1 python nlp_to_structured_data_mcp_client.py --sample sales --query "test"

System Requirements

  • Python: 3.8 or higher
  • Memory: 4GB RAM minimum
  • Dependencies: See requirements.txt
  • AWS: Bedrock access required for Claude AI
