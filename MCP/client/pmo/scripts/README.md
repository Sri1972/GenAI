# Chart Library Scripts

This directory contains local copies of JavaScript charting libraries with automatic CDN fallback.

## Directory Structure

```
scripts/
├── d3_js/
│   └── d3.v7.min.js         (273 KB) - D3.js v7 visualization library
└── chart_js/
    ├── chart.umd.min.js     (200 KB) - Chart.js v4.4.0 charting library
    └── chartjs-plugin-datalabels.min.js (13 KB) - DataLabels plugin
```

## Total Size: ~486 KB

## How It Works

Charts generated by the MCP server automatically use these local files with fallback to CDN:

1. **Local First**: Tries to load from `scripts/` directory
2. **Automatic Fallback**: If local file missing, loads from CDN
3. **Zero Configuration**: Transparent to users

## Configuration

Library paths are configured in constants at the top of each file:

### D3.js Configuration (`d3_chart_api_server.py`)
```python
D3_LOCAL_PATH = 'scripts/d3_js/d3.v7.min.js'
D3_CDN_URL = 'https://d3js.org/d3.v7.min.js'
D3_SCRIPT_TAG = f"<script src='{D3_LOCAL_PATH}' onerror=\"this.onerror=null; this.src='{D3_CDN_URL}';\"></script>"
```

### Chart.js Configuration (`chart_renderer.py`)
```python
CHARTJS_LOCAL_PATH = 'scripts/chart_js/chart.umd.min.js'
CHARTJS_CDN_URL = 'https://cdn.jsdelivr.net/npm/chart.js@4.4.0/dist/chart.umd.min.js'
CHARTJS_DATALABELS_LOCAL_PATH = 'scripts/chart_js/chartjs-plugin-datalabels.min.js'
CHARTJS_DATALABELS_CDN_URL = 'https://cdn.jsdelivr.net/npm/chartjs-plugin-datalabels@2.2.0/dist/chartjs-plugin-datalabels.min.js'
```

## Updating Libraries

To update to newer versions:

1. Download new library files
2. Replace files in appropriate directory
3. Update version numbers in constants (if URL changed)

### Update D3.js
```powershell
cd scripts/d3_js
Invoke-WebRequest -Uri "https://d3js.org/d3.v7.min.js" -OutFile "d3.v7.min.js"
```

### Update Chart.js
```powershell
cd scripts/chart_js
Invoke-WebRequest -Uri "https://cdn.jsdelivr.net/npm/chart.js@4.4.0/dist/chart.umd.min.js" -OutFile "chart.umd.min.js"
Invoke-WebRequest -Uri "https://cdn.jsdelivr.net/npm/chartjs-plugin-datalabels@2.2.0/dist/chartjs-plugin-datalabels.min.js" -OutFile "chartjs-plugin-datalabels.min.js"
```

## Benefits

✅ **Offline Capable**: Works without internet after initial setup  
✅ **Corporate Compliant**: No CDN dependency required  
✅ **Faster**: ~500ms faster chart generation (no network latency)  
✅ **Resilient**: Automatic fallback if files corrupted/missing  
✅ **Centralized**: All paths managed in constants for easy updates
