KEY CONCEPTS:

1️⃣  Natural Language → Structured Data
   "Create org chart with 3 levels" 
   → 
   shapes: [{shape_type: "rounded_rectangle", left: 3.5, top: 1.5, ...}, ...]

2️⃣  LLM Makes All Design Decisions
   - Which shapes to use (rectangles, circles, arrows, etc.)
   - Colors (professional color schemes)
   - Positioning (evenly spaced, hierarchical, grid, etc.)
   - Sizing (auto-sized or custom)
   - Layout (horizontal, vertical, matrix, etc.)

3️⃣  No Manual Data Structuring Required
   User just describes intent → LLM figures out implementation

4️⃣  Context Aware
   "Add another with different colors" → LLM remembers previous slides

5️⃣  Extensible
   Add new tool → Document it → LLM automatically uses it
